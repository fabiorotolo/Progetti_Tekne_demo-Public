# Progetti Tekne · demo

Versione dimostrativa di **Progetti Tekne**, la pianificazione delle attività dei reparti tecnici.

Apri la demo: **https://fabiorotolo.github.io/Progetti_Tekne_demo-Public/**

- Si entra scegliendo un nome (nessuna password).
- Tutto gira nel browser: le modifiche restano solo sul tuo PC.
- Il pulsante "Ripristina dati di esempio" in basso riparte da capo.

Questo repository contiene solo la pagina generata; il codice del progetto è altrove.
